# Applied-Math-Research-2026

My name is Dhruv Pandey and this is my first research project going in depth about mathematical concepts and their application into certain topics.

## Research Question

To what extent do increasingly complex machine learning models improve predictive performance compared to classical statistical methods when forecasting financial time-series data?

## Goal

This project investigates the relationship between model complexity, prediction accuracy, and overfitting in financial forecasting. This project will also investigate the influence of machine learning compared to the influence of statistical or quantative methods in financial forecasting.

## Methods

- Statistical models
- Machine learning models
- Data analysis using Python
